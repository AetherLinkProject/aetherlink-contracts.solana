# Project Overview and Structure

## Module Overview

### 1. OracleNode
Represents a registered oracle node. Each node is uniquely identified and managed by its authority. Contains metadata and status fields.

- **Fields:**
  - `authority`: Node owner (Pubkey)
  - `node_id`: Unique node ID (u64)
  - `status`: Node status (0=inactive, 1=active, 2=disabled)
  - `metadata`: Node metadata (description, external ID, etc.)
  - `bump`: PDA bump

### 2. SenderAuthority
Defines whitelisted sender accounts for cross-chain operations.

- **Fields:**
  - `authority`: Account address (Pubkey)
  - `enabled`: Whitelist status (bool)

### 3. ChainWhitelist
Manages the list of supported chain IDs for cross-chain messaging.

- **Fields:**
  - `chain_id`: Supported chain ID (u64)
  - `enabled`: Whitelist status (bool)

### 4. ChainMessage
Represents a cross-chain message, including sender, receiver, source/destination chains, payload, and status.

- **Fields:**
  - `sender`: Sender address (Pubkey)
  - `receiver`: Receiver address (Pubkey)
  - `src_chain`: Source chain ID (u64)
  - `dst_chain`: Destination chain ID (u64)
  - `payload`: Message content ([u8; 128])
  - `status`: Message status (0=pending, 1=completed, 2=failed)
  - `bump`: PDA bump

## Core Instructions

- **register_node**: Register a new oracle node with metadata.
- **update_node**: Update node status and metadata.
- **manage_whitelist**: Enable or disable sender/chain whitelist entries.
- **send_request**: Initiate a cross-chain message request.
- **receive_message**: Mark a cross-chain message as received and update its status.
